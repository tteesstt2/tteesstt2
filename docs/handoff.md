## 1. 만들려는 서비스

- 유튜브 영상 링크를 받으면 **Gemini API**로 분석해 **장소와 장면**을 추출한다.
- 대상은 **일본 여행 브이로그**부터. 다른 국가·장르로 확장할 수 있게 설계한다.
- 추출은 **영상에서 보이거나 들리는 사실 위주**로 한다 (간판 글자, 음성 언급, 랜드마크). 근거 없는 장소명은 저장하지 않는다.
- **관리자(사용자 본인)** 가 추출된 장소를 보고 **구글맵 기준으로 이름·좌표를 수동 검증**한다.
- 사용자는 **구글처럼 검색**해서 장소·장면을 찾고, 해당 영상의 그 시점으로 이동한다.

## 3. 결정된 사항

1. **장면 1개 = 검색 문서 1개.** 결과는 영상 시점 링크(`?t=초`)로 연결. 영상 다운로드·프레임 캡처는 하지 않음(유튜브 약관).
2. **AI(Gemini)는 저장할 때 쓰고, 검색할 때는 기본적으로 쓰지 않는다.** 검색은 사전 + 패턴 규칙 + 의미(벡터) 검색으로 처리. 긴 문장 해석용 Gemini 호출은 선택 옵션으로 기본 꺼둠.
3. **해석 결과는 걸러내기가 아니라 가산점으로** 사용 (해석이 틀려도 결과가 사라지지 않게).
4. 검색 결과에 나오는 장소는 **우리 DB에 있는(검증된) 장소뿐**이다. 그래서 검색어를 완벽히 이해할 필요 없이 "우리 장소 중 무엇과 관련 있나"만 판단하면 된다.
5. 질문형 검색어("도쿄역 근처 카페")는 **조각별 역할 부여 → 틀에 맞추기**로 해석한다.
   - 기준 장소(도쿄역)가 DB에 없으면 지도 API로 좌표를 얻고, 그 반경 안의 우리 장소를 찾는다.
   - 장소 종류(카페 등)는 구글맵 장소 유형을 활용한다.
6. 사전은 **외부 데이터로 크게 채우고**(Wikidata, 위키백과 넘겨주기, OSM, 영상 제목), **영상 분석 결과에서 자동 생성**(음성 "이치란" + 간판 "一蘭" → 별칭 쌍), **운영 중 검색 기록으로 보강**한다.
7. 검색 기술 초안: **PostgreSQL + PGroonga(한·일 전문 검색) + pgvector(의미 검색)** 로 시작, 커지면 OpenSearch. 검색 로직은 별도 모듈로 분리.
8. 스크래핑(구글 자동완성, 구글맵, 지식iN 페이지 등)은 하지 않는다. 공식 API·공개 데이터만 사용.

## 4. 결정이 필요한 사항 (열린 질문)

- **구글맵 데이터 저장 방식**: Google Places 약관상 place_id 외 데이터(좌표 등)는 영구 저장이 제한될 수 있음 (최신 약관 확인 필요).
  - (1) place_id만 영구 저장, 이름·좌표는 API로 받아 주기적 갱신, 지도는 구글맵 사용
  - (2) 좌표는 자체 확인값 또는 OpenStreetMap 기준으로 저장, 구글맵은 참고용
- DB 호스팅(PGroonga 지원 여부: Supabase 지원, AWS RDS 미지원)
- 개발 언어·프레임워크 (아직 미정)

## 5. 환경 설정 상태

| 항목 | 상태 |
|---|---|
| GitHub push | 동작함 (브랜치 `claude/code-work-confirmation-3t3e7c`) |
| 네이버 검색 API | 키 발급 완료. 환경의 "API 자격 증명"(Bearer 유형 + 사용자 지정 헤더)으로 넣었으나 **인증 실패** (`NID AUTH Result Invalid`). 자격 증명 유형이 `Authorization` 헤더 방식뿐이라 네이버의 `X-Naver-Client-Id/Secret` 헤더 방식과 맞지 않는 것으로 추정. **대안: 환경 변수** `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` |
| YouTube Data API | 키 발급 예정. 환경 변수 `YOUTUBE_API_KEY` 로 넣기로 함 (콘솔에서 YouTube Data API v3로 키 제한). `www.googleapis.com` 연결은 가능 |
| Gemini API | 아직 키 없음. 영상 분석 PoC에 필요 |
| 네트워크 | `openapi.naver.com`, `www.googleapis.com` 연결 가능. `trends.google.com` 차단 |

환경 변수·네트워크 설정은 claude.ai/code 환경 설정(환경 "기본값" → 편집)에서 바꾸며, **새 세션부터 적용**된다. 키 값은 채팅에 붙여넣지 않는다.
